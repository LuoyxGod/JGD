# 聚光灯 GameJam · 玩法原型测试计划书

## 一、目的
在正式进入 Unity 3D 开发前，用网页端快速验证核心玩法闭环是否成立、是否好玩：

> 探索初始十字地块 → 搜集"记忆物" → 获得地图拼图 → 打开地图面板拼合道路 → 切回 3D 画面，世界扩展 → 继续探索

## 二、原型范围（做 / 不做）

**做：**
1. 3D 俯视角第三人称移动（Three.js，WASD / 方向键），镜头平滑跟随。
2. 初始世界：由 5 个 50m×50m 地块组成的十字形区域，背景纯白。
3. 2 个可交互记忆物（发光球体，靠近按 E 拾取），每件对应一张地图拼图。
4. 地图面板（按 M 打开）：
   - 左侧：拼图板（网格），已解锁的十字地块以绿色显示；
   - 右侧：物品栏（存放搜集到的拼图，与图1布局一致）；
   - 拼图可拖拽、R 键旋转、吸附网格、可放回物品栏；
   - 「确认拼合」按钮校验位置。
5. 拼对后关闭面板，3D 世界中新地块出现（带出现动画），道路在拼图上连续可辨。
6. 碰撞：玩家只能站在已解锁地块上，不能走出到虚空。

**不做（原型阶段砍掉）：**
- 剧情、对话、音频、美术资源；
- 存档、UI 动效打磨、移动端适配。

## 三、地块与拼图数据设计

世界网格坐标 (cx, cz)，每格 50m：

| 区域 | 格子 | 解锁条件 |
|---|---|---|
| 十字初始区 | (0,0) (0,1) (0,-1) (-1,0) (1,0) | 初始解锁 |
| 蓝色 L 形拼图区 | (2,0) (2,-1) | 拼图① 拼对 |
| 绿色 2×2 区 | (3,0) (3,-1) (4,0) (4,-1) | 拼图② 拼对 |

道路（拼图上的关键信息）：
- 十字区：横穿道路 z=25，x ∈ [-50, 100]
- 拼图①：道路延续 z=25，x ∈ [100, 150]（提示它应接在十字区右侧）
- 拼图②：L 形道路 (150,25)→(175,25)→(175,-75)（提示 2×2 区的朝向与位置）

校验规则：拼图放置后的绝对格子集合与目标区域完全一致即成功（原型不要求与道路断点校验，观察道路是给玩家的引导而非程序校验）。

## 四、验收标准
1. 玩家 30 秒内能学会移动与拾取（有按键提示）。
2. 地图面板拖拽/旋转/吸附操作流畅，误操作可撤销。
3. 拼对瞬间切回 3D 有明确的"世界生长"反馈（新地块动画 + 提示文字）。
4. 全流程（2 次拼图）可在 3 分钟内走通。

## 五、技术方案
- 单文件 `prototype.html`，Three.js（CDN r128），无构建步骤，双击浏览器即可玩。
- 地图面板为 HTML Canvas + DOM 覆盖层。
